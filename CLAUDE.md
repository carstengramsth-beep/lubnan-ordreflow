# Vigtigt om kommunikation

- Skriv ALTID på dansk til brugeren.
- Brugeren har en hjerneskade. Brug korte sætninger og enkle ord.
- Forklar ét trin ad gangen. Undgå tekniske ord (fx GitHub-ord) eller forklar dem kort.
- Bed ikke brugeren om at gøre ting i GitHub, med mindre det er helt nødvendigt.

# Fast aftale om fakturaer i Outlook (Carsten)

- Claude lægger nye indkomne fakturaer i disse mapper:
  - Firma (C&E Holding og Paritas Kolding): **18. Indkomne Fakturaer C&E og PK**
  - Privat: **18,3 Indkomne regninger Privat**
- Carsten tjekker selv i banken, om fakturaen er betalt.
- Når den er betalt, flytter Carsten den selv til:
  - Firma: **18.1 betalte fakturaer C&E og PK**
  - Privat: **18.5 Betalte Private regninger**
- Claude flytter ikke fakturaer til "betalte"-mapperne, med mindre Carsten beder om det.
- Claude kan ikke se banken og ved derfor ikke, om noget er betalt.
